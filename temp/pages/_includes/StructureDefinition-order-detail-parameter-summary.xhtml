Summary

Complex Extension: Structured key-value parameters for order details. This extension pre-adopts the R6 ServiceRequest.orderDetail.parameter structure to enable computable order instructions in R4. Each instance represents one parameter with a code and a typed value.

  • code: CodeableConcept: A code or identifier that names this parameter, such as 'monitoring-cadence' or 'reflex-testing-enabled'.
  • value[x]: boolean, dateTime, integer, string, CodeableConcept, Quantity: The value of the parameter. Type varies based on the parameter code.
