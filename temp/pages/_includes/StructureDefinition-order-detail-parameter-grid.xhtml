NameCard.TypeConstraints and Usage
  Extension 0..* Extension ele-1: All FHIR elements must have a @value or children
ext-1: Must have either extensions or value[x], not both
Definition:
Structured key-value parameters for order details. This extension pre-adopts the R6 ServiceRequest.orderDetail.parameter structure to enable computable order instructions in R4. Each instance represents one parameter with a code and a typed value.

  extension
     (code) 		1..1 Extension ele-1: All FHIR elements must have a @value or children
ext-1: Must have either extensions or value[x], not both
Definition:
A code or identifier that names this parameter, such as 'monitoring-cadence' or 'reflex-testing-enabled'.

  extension
     (value[x]) 		1..1 Extension ele-1: All FHIR elements must have a @value or children
ext-1: Must have either extensions or value[x], not both
Definition:
The value of the parameter. Type varies based on the parameter code.
